# Marbble roadmap

**Stage: alpha.** Next: beta.

Marbble aims to be what Pro Tools is among DAWs: not every feature Logic Pro has, but a complete,
solid core for recording, editing, mixing and delivering, that runs well and never loses work, with
plug-ins doing the rest. This page says what beta needs, how far along that is, and what's being
worked on. The [feature list](docs/FEATURES.md) has every Logic Pro feature by area and how far
Marbble has it, and every open item is an [issue][issues].

## What beta needs

- **The core features.** Every feature marked `beta = true` in [`features/`](features/README.md):
  the essentials of Logic Pro's interface, projects, transport, recording, tracks, arranging,
  editors, Mixer, plug-in hosting, MIDI devices and bouncing. Logic's extras (the Brush tool, the
  Toolbar, the giant display, several open projects and the like) wait until after beta.
- **Stages 1 and 2 below.** Prereleases that install cleanly, and plug-ins that work the same on
  Windows and macOS as on Linux.
- **No known bug that crashes or loses work**, and the checks labelled [`needs a look`][needs a look]
  and [`needs listening`][needs listening] done.

What's left for beta, by area (◐ partial, ○ missing):

**Interface and settings**

- ◐ Control bar: view buttons, transport, LCD, Cycle, Count-in, Metronome, master volume, CPU: Fixed layout; no Customize Control Bar.
- ◐ LCD display modes: Beats and Time only; no Custom mode or large LCD.
- ◐ Right inspector strip follows the left strip's output or aux: Always shows Stereo Out.
- ◐ Project notes: Free-form notes in Project Settings; no Note Pad pane.
- ○ Track notes
- ◐ Zoom to fit selection or all content (Z): In the Piano Roll and Audio Track Editor; not in the Tracks area.
- ◐ Open, close and focus windows: The Window menu brings any open window to the front or minimises it, and the Mixer, Editors, Event List, Step Sequencer and effect panels open in windows of their own; no second main window.
- ◐ Customisable keys: Window keys only; menu shortcuts are fixed.
- ○ Save, import and choose key command sets
- ◐ Project Settings: Tempo, signature, key, sample rate, bit depth, metronome and notes; most of Logic's project panes are missing.
- ○ Reset all settings
- ○ Notifications: reset "don't show again" warnings

**Projects**

- ◐ Project Chooser: New, Recent and Open, with four built-in templates and the user's own (My Templates); no demo projects or tutorials.
- ◐ Save a copy including all assets: Save As into a new folder copies every file the project uses into it; no Save a Copy As that leaves the open project as it is.
- ○ Delete a project from the chooser
- ○ Project start and end points
- ○ Close Project without quitting

**Transport and tempo sync**

- ◐ Stop hung notes: Stopping releases the sustain pedal and re-centres pitch bend; no explicit panic command.
- ○ Pause, fast forward and rewind, Play from Left Window Edge, Play from Selection
- ○ Transport shortcut menus on Play and Stop
- ○ Go to Position dialog (/)
- ○ Set locators numerically in the LCD
- ○ Skip cycle; move, double or halve the cycle by its length (key commands, p. 1121)
- ○ Forward and rewind by transient (key commands, p. 1121)
- ○ Route the click to its own output, or send it as MIDI

**Tracks**

- ◐ Change header controls on several tracks: Track On, Mute, Solo and Record Enable in the track menu, the Freeze button and the icon act on the selected tracks; the header's own buttons and volume only through groups.
- ○ New track for overlapped regions
- ○ Search for and select a track
- ○ Rename several tracks at once
- ○ Sort tracks
- ○ Configure Track Header: choose which controls show

**Arranging**

- ◐ Loop continuously: Loops to the next region, or four times the length when nothing follows.

**Editors**

- ◐ Piano Roll tools: Pointer, Pencil, Eraser, Velocity, Mute, Scissors, Glue, Line; no Brush, Quantize, Solo or Zoom tools.
- ◐ Delete events: No Delete Outside Region or Delete Unselected Within Selection.
- ○ Add notes constrained to a scale
- ○ Time handles: stretch selected notes
- ○ Drum names and Collapse Mode views
- ◐ Piano Roll as a separate window, with Link mode: The Editor detaches and follows the selection; no Link modes.
- ○ Lock event positions
- ○ Track and region automation shown in the Piano Roll
- ○ Show automation in the Audio Track Editor

**Mixing and automation**

- ◐ Channel strip types: Audio, instrument, aux, summing stack, VCA and Stereo Out; no MIDI, output or master strips.
- ◐ Reorder strips: Follows the track order.
- ◐ Search for plug-ins: The Library has search; slot menus are grouped by vendor and category, without search.
- ◐ Plug-in windows: Built-in effect panels everywhere; a VST3's own editor on Linux/X11 and macOS so far.
- ○ Select several strips, or strips by type

**Plug-ins**

- ◐ Plug-in Manager: Hide plug-ins, add VST3 folders, rescan, view the scan report; no categories or custom names.

**MIDI and hardware**

- ◐ Receive MIDI from other apps: Through system MIDI ports; Marbble doesn't create a virtual port of its own.
- ○ Local Off: stop a keyboard's own sound generation

**Import, export and media**

- ◐ All Files Browser: Browses folders; no search conditions or bookmarks.
- ○ Open a MIDI file as a new project
- ◐ Bounce file formats: WAV and AIFF at 16, 24 or 32-bit float, FLAC at 16 or 24-bit; no CAF, MP3 or M4A.
- ◐ Dither: TPDF only; no POW-r.
- ◐ Bounce all tracks in place: Works on the selected tracks; no dedicated command.
- ○ Real-time bounce

## Current focus

Work goes in rounds of a few issues at a time. What's being built right now is in the issues
labelled [`in progress`][in progress]. The rounds planned towards beta:

1. **Plug-in hosting.** Several processing threads on macOS and Windows ([#59]), keys from VST3
   editors on Linux ([#88]), editors following a display scale change ([#94]), the Plug-in Manager,
   plug-in search and plug-in windows in the Mixer, Compare for VST3 plug-ins ([#292]); then CLAP
   hosting ([#105]).
2. **Transport and navigation.** Pause, fast forward and rewind, Play from Selection, Go to
   Position, locators typed into the LCD, the cycle and transient key commands.
3. **Projects, tracks and delivery.** Save a copy with its assets, Close Project, project start and
   end, opening a MIDI file as a project, real-time bounce and dither, searching, renaming and
   sorting tracks.
4. **Editing and the Mixer.** Scale-constrained note input, time handles, note labels and drum
   names in the Piano Roll, selecting and reordering Mixer strips, the track header's width and
   controls, key command sets.

## Stages

The stages are [milestones][milestones] on GitHub, in the order they matter for a usable release.

### Stage 1: Release hygiene

Goal: prereleases that install cleanly and that people can trust with their projects.

- [ ] Code signing on Windows (Authenticode) and signing plus notarization on macOS ([#97], [#98])
- [x] A LICENSE file (MIT, shipped in every bundle)
- [ ] Hands-on testing of the Windows and macOS builds: devices, MIDI, plug-in scanning,
      installers, file dialogs ([#32], [#33], [#34])
- [x] Automation lanes follow a plug-in moved to another track
- [x] Make `takes_check` "autopunch trims the take" deterministic (it was a real race: a
      position read right after a locate could return the old playhead)
- [x] Run the headless checks that need no plug-ins in CI on Linux (`scripts/headless-checks.sh`)

### Stage 2: Plug-ins on every platform

Goal: a VST3 user on Windows or macOS gets the same workflow as on Linux.

- [ ] VST3 editor windows on Windows (HWND embedding) ([#99])
- [x] VST3 editor windows on macOS (NSView embedding)
- [x] VST3 editors with the interface on native Wayland (opt-in, `MARBBLE_WAYLAND=1`; the
      editors stay XWayland windows)
- [x] HiDPI scaling for plug-in editors (`IPlugViewContentScaleSupport`, Linux)
- [ ] ASIO on Windows ([#100])
- [x] Side-chain inputs for VST3 plug-ins
- [x] Multi-output instruments

### Stage 3: Audio editing

Goal: clean, fast audio editing and comping without workarounds.

- [x] Crossfades between adjacent regions, and automatic crossfades on edits
- [x] Fade curve shapes and fade types (equal power, speed-up, slow-down)
- [x] Drag modes: No Overlap, Shuffle Left and Right (Overlap and X-Fade are done)
- [x] Crossfades for take folders and looped regions; Logic's Crossfade Time and Curve settings
- [x] Marquee tool, a Tool menu in the tracks area, and Scissors, Glue, Fade, Pencil and Eraser
- [x] Region gain drag; snap edits to zero crossings
- [x] Region drags in bars and beats across tempo changes
- [x] Several comps per take folder; MIDI cycle recording into take folders
- [x] Move automation with regions
- [x] Trim AAC/M4A encoder delay exactly on import
- [x] Logic's arranging commands: select by criteria, section edits between the locators, Trim,
      Remove Gaps, Paste Replace, Strip Silence

### Stage 4: MIDI and control

Goal: precise MIDI editing and hands-on control from hardware.

- [x] MIDI learn and controller assignments for plug-in and mixer parameters
- [x] Event List
- [x] Step Input (Musical Typing, MIDI keyboard, rests)
- [x] Region playback parameters: non-destructive quantize, transpose, velocity, delay
- [x] Record MIDI in Replace mode
- [x] Chase notes that started before the playhead
- [x] Controller curve shapes

### Stage 5: Mixing and delivery

Goal: finish a mix and deliver it without leaving Marbble.

- [x] Channel strip settings; copy and paste a whole strip
- [x] Several automation lanes per track, automation curves, automation for folder stacks and
      Stereo Out
- [x] Undo for parameter changes made in a VST3's own editor
- [x] VCA faders
- [x] A pre-fader side-chain option for built-in effects
- [x] Clip indicators and a gain-reduction meter on the strip
- [x] FLAC and AIFF bounce; export the selected tracks
- [ ] MP3 and AAC bounce (needs an encoder whose licence suits) ([#101])
- [x] Delay compensation changes while playing without clicks
- [x] More built-in effects: modulation (chorus, flanger, phaser, tremolo), distortion, a Gain
      utility
- [x] A linear-phase EQ

### Stage 6: Advanced production

Goal: the larger Logic features that set a full DAW apart.

- [ ] Flex Time ([#102])
- [ ] Flex Pitch ([#103])
- [x] Track alternatives; project alternatives and backups; user project templates
- [x] Arrangement track; markers with their own lengths
- [x] Step Sequencer: pattern regions, rows of steps, edit modes, polymeter, swing
- [x] Multi-core track processing: Settings › Audio › Processing Threads, bit-identical to one thread
- [ ] Score Editor ([#104])

### Stage 7: Formats and reach

Goal: more plug-ins, more people.

- [ ] CLAP hosting ([#105])
- [ ] Audio Units on macOS ([#106])
- [ ] Screen reader support ([#107])
- [ ] Translated interface ([#108])

## Open work

Besides each stage's milestone, a few labels gather the open work that doesn't belong to one stage:

- [`bug`][bug]: known bugs and unexplained failures.
- [`needs a look`][needs a look]: built and tested, but not yet checked by eye in the running app.
- [`needs listening`][needs listening]: passes its checks, but nobody has listened to it or tried it
  on a real interface yet.
- [`platform: windows`][platform: windows] and [`platform: macos`][platform: macos]: what still
  needs a real Windows or Mac.
- [`flaky test`][flaky test]: checks that fail now and then.
- `area: …` labels group the rest by part of Marbble ([instruments][area: instruments],
  [sampler][area: sampler], [multi-core][area: multi-core], [ui][area: ui] and so on).
